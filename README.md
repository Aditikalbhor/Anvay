# ANVAY — Smart Building Navigation & Emergency Guidance System

ANVAY is a smart indoor navigation and emergency guidance system designed for navigating complex educational buildings.

## 🚀 Features

* 🔐 User authentication
* 🔎 Search for rooms and locations
* 🗺️ Interactive floor maps
* 📍 Indoor navigation
* 🧭 Dynamic route guidance
* 🚨 Emergency guidance
* 🔄 Route recalculation when a path is blocked
* 📱 Interactive building navigation

## 🛠️ Tech Stack

* **Language:** Java
* **Platform:** Android
* **UI:** XML
* **IDE:** Android Studio / Antigravity IDE
* **Build System:** Gradle

## 🏫 Project Scope

The current implementation focuses on the **Computer/IT Building of Government Polytechnic Pune**, covering:

* Ground Floor
* First Floor
* Second Floor

## 📱 Application Flow

```text
Login / Guest Access
        ↓
Home Dashboard
        ↓
Search Location
        ↓
Select Destination
        ↓
View Floor Map
        ↓
Indoor Navigation
        ↓
Emergency Guidance
```

## 🚨 Emergency Guidance

ANVAY can provide guidance toward safer exits during an emergency and supports dynamic route changes when a particular route becomes unavailable.

## ⚙️ Setup

### Prerequisites

* Android Studio
* JDK
* Android SDK
* Android device or emulator

### Run the Project

1. Clone the repository.
2. Open the project in Android Studio.
3. Allow Gradle to sync.
4. Connect an Android device or start an emulator.
5. Build and run the application.
